# Link Steward — GitHub Pages

Публичная копия сайта и руководства для сохранения прежних адресов:
https://maeshchenko.github.io/link-steward/

Основной сайт: https://misheno.com/link-steward/ . Canonical URL каждой страницы указывает на Misheno. Старые адреса содержат полные страницы, поэтому документация доступна без JavaScript и перенаправлений.

## Содержимое

`public/` содержит только восемь HTML-страниц, favicon, шрифт с лицензией, CSS и изображения. Код приложения хранится отдельно в приватном `maeshchenko/link-steward-app`. У этого репозитория своя независимая история.

## GitHub Pages

В **Settings → Pages → Build and deployment → Source** выбрать **GitHub Actions**. Workflow **Deploy GitHub Pages** публикует только `public/` при обновлении `main`; также доступен ручной **Run workflow**. Custom domain оставлять пустым, чтобы сохранился прежний адрес GitHub Pages.

Проверка перед публикацией:

```sh
python3 scripts/check-site.py
```

Она проверяет точный состав публичных файлов, внутренние ссылки и фрагменты, отсутствие кода приложения в корне, соответствие сохранённым SHA-256 и canonicals Misheno. Сайт не требует Node.js или сборки.

## Поддержка копии

Исходные страницы редактируются в репозитории Misheno, в `public/link-steward/`. При обновлении этой копии перенести только перечисленные в `site-source.json` публичные файлы, заменить корневую ссылку на Misheno полным URL и обновить SHA-256. Основной текст руководства и юридических страниц должен совпадать с Misheno.

Сохранять эту публикацию, пока прежние адреса используются в Marketplace и отправленных материалах проверки.
