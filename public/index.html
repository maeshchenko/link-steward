How do I find broken links in Confluence Cloud?

Once Link Steward is installed, open it from Confluence Apps, choose a space, and run a scan. Review the Broken and Needs review results with the page owners. A space administrator must enable any external domains first. Public installation is not yet available while Marketplace review is in progress. See the setup guide.

Will Link Steward change my pages automatically?

Link replacements are published only after an authorized user previews and saves them. Optional owner reminders are off by default; when enabled, they can add a native page comment. Learn more in the replacement guide.

Does it check every kind of link?

The app checks supported links in published Confluence pages and administrator-enabled public HTTPS destinations. Plain text URLs, third-party macro internals, URL fragments, and content meaning are not checked. Read the limits and recovery guide.

Can I replace the same URL across multiple pages?

Yes. Preview replacements on up to 20 selected pages at a time. Exact mode replaces a complete URL; base mode updates a domain or path prefix while preserving the remaining path, query, and fragment. Visible link labels stay the same. See the URL replacement examples.

Can I schedule scans and remind page owners?

A space administrator can enable daily or weekly scans. Optional owner reminders add a Confluence comment for open, confirmed broken links and are off by default. Confluence controls notification delivery. Read about exceptions and reminders.

Does Link Steward check Smart Links and anchors?

Link Steward reads standard hyperlinks and inline, card, and embed Smart Link destinations in published pages. It checks supported Confluence page targets and enabled external HTTPS destinations. It does not verify whether a URL fragment reaches the right heading. See the supported links and scan limits.

Is Link Steward free?

Link Steward is free for up to 10 users, with paid plans for larger teams. Contact support for questions about your team.
