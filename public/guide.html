Link Steward for Confluence / Release 1.0

Link Steward guide

Set up a space

Install Link Steward from Atlassian Marketplace, then open Apps → Link Steward for Confluence. Choose a space. A Confluence space administrator can configure and scan it.

In Settings, enter exact external hostnames, one per line, such as docs.example.com. Include redirect destinations if those are also trusted. Internal Confluence page links are checked without an external-domain rule. External checking is disabled until a domain is enabled.

Choose Off, Daily or Weekly automatic checks, then save. Scheduled checks start within approximately an hour after becoming due, subject to Forge availability and quotas. A manual scan can be started immediately. Only one space scan runs at a time. Use Stop scan to stop a stalled or unwanted run and start a fresh one.

Review the queue

My queue follows the current Confluence page owner. All links includes only pages you can currently read. Use search, owner, work-state and link-result filters. A transfer of page ownership transfers the queue on refresh. If an owner profile is unavailable, an administrator can still manage accessible issues and transfer ownership in Confluence.

Link resultMeaning
AvailableAn enabled external destination returned a successful response, or the Confluence target is accessible.
BrokenThe public external destination returned HTTP 404 or 410.
Needs reviewPermissions, authentication, throttling, network trouble, configuration or unsupported content prevent a conclusion.
ExcludedA space rule prevents this destination from being checked.
Link removedA later check confirmed that the URL no longer appears on the source page.

Mark in progress records work. Ignore leaves an exception outside the default queue. Reopen restores it. Recheck queues the page for another check. Success or confirmed removal resolves an earlier issue; a later failure opens it again. A link that has always been available has No issue and does not inflate the count of fixes.

Select up to 50 rows for work-state changes or page rechecks. Use Owners to review progress and recent scans. Export CSV downloads the currently filtered, loaded results. Share exports only with people entitled to the page titles, URLs and owner names they contain.

From a page, open More actions → Apps → Link Steward for Confluence to review only that page and use Check this page. Show whole space returns to the space report.

Replace links

Select results on the pages to edit, choose Replace links, and enter the old and new destinations. An exact replacement matches the complete URL. A base replacement matches the origin and path boundary and preserves each matching link's query and fragment. It does not rewrite visible link labels.

Choose Preview changes. Review the old/new destinations and selected pages, then save. Up to 20 pages can be included. Keep the view open until every page has a result; each successful save creates a Confluence version. A failed page does not undo already saved pages. If the page or its unpublished draft changes, create a new preview. Use Confluence version history to restore a previous page version when necessary.

Exceptions and reminders

Domain exclusions skip all matching destinations. Select rows and choose Exclude URLs for exact URL exclusions across a space. Remove a rule in Settings and recheck the affected pages to update results.

Owner reminders are off by default. Enabling them lets Link Steward add a native page comment mentioning the current owner when that page has open, confirmed broken links. Ignored, in-progress and uncertain results do not trigger reminders. Repeated checks do not repeat the comment within seven days. Confluence may notify watchers according to their preferences; email delivery is not guaranteed.

Limits and recovery

A space scan checks at most 1,000 published pages and 10,000 links, with at most 100 unique links per page. A limit or unreadable ADF produces an incomplete result. Archived, deleted and inaccessible source pages are not exposed in your report. Plain text URLs and third-party macro internals are not scanned. URL fragments and content meaning require manual review.

Results and work states expire after 30 days. A removed-link result is retained for up to 30 days within a bounded page record; up to 200 current and removed results fit in one page record. Refresh after an action to see asynchronous results. Retry a failed scan when the service is available again.

Delete data and uninstall

Turn off schedules and reminders in Settings. A space administrator can choose Delete app data for this space and confirm. This clears configuration, results and work states for that space. Existing Confluence page versions and reminder comments remain Confluence content; app data deletion does not erase them. Site administrators can uninstall Link Steward in Connected apps. Atlassian's platform retention policies apply after uninstallation.
