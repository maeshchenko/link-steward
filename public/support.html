Link Steward support and troubleshooting

Email support@misheno.com for product support. The provider is Mikhail Eshchenko. No guaranteed response time or 24/7 support is offered in release 1.0.

Contact support

Include the app version, approximate time of the problem, operation attempted, visible error code and whether it affects a page or a space. Redact page content, private URLs and owner details in screenshots. Never send passwords, session cookies, authorization headers or API tokens.

Troubleshoot link checks

Before reporting a failed check, confirm that the exact destination and redirect hostnames are enabled in Settings. Access restrictions, authentication, rate limits and server failures are Needs review results, not proof of a broken link.

Compare the link result definitions and scan limits before retrying a check.

Troubleshoot URL replacements

A page that changed after the replacement preview needs a fresh preview. Publish or discard actual unpublished draft changes before replacing links.

Follow the replacement steps and examples. If some pages were saved before a failure, those changes remain; use Confluence version history to restore a page if necessary.

Report a security issue

For suspected security issues, use the same provider contact and put “Security report” in the subject. Describe the affected feature and a minimal reproduction using disposable content. Do not access another customer's data or test a third-party destination without authorization. The provider will assess the report and coordinate remediation and any required notification through Atlassian's security process.
